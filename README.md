## 🕹️ Interactive Commands
Once running in your terminal, you can interact with the agent using:
- `memoria` — Inspects the current nodes stored in the magnetic field.
- `listar skills` — Lists all autonomously generated skills.
- `/cmd <command>` — Executes direct operating system commands (e.g., `/cmd git status`).
- `sair` — Safely saves the magnetic field state and shuts down.
